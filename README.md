# Cloud Posture Dashboard

### Problem Statement

Cloud security engineers often manage multiple cloud accounts across AWS, Azure, and GCP, making it difficult to identify and prioritize security misconfigurations. A simple, centralized dashboard can help them view, filter, and investigate issues efficiently.

### Understanding of the User Persona

The primary user is a cloud security engineer or cloud administrator responsible for monitoring multiple cloud accounts and keeping them secure. They need to quickly identify critical issues, filter findings by provider, account, severity, and status, and understand how to fix problems. They prefer a clear, straightforward interface that saves time and avoids unnecessary complexity.

### Proposed Features
My idea is to create a simple dashboard that helps security teams check for security problems across different cloud accounts, such as AWS, Azure, and Google Cloud. The dashboard shows how many issues exist and highlights the most serious ones. Users can search for issues and filter them by cloud provider, account, severity, or status. When they select an issue, they can understand what went wrong and follow simple steps to fix it.

### Feature Prioritization
I focused on the features that users need most. First, I made critical issues easy to spot so users know what needs attention first. Second, I added search and filters to help users find specific problems quickly. Finally, I included clear explanations and steps to fix each issue. I kept the design simple and avoided unnecessary charts and complicated features so that users can understand and use the dashboard easily.

### Success Metrics
To understand whether the dashboard is useful, I would measure:

- **Time to find an issue:** How quickly users can locate an important security problem.
- **Task completion:** Whether users can successfully find and understand a specific issue.
- **Time to fix an issue:** How long it takes to resolve a problem after finding it.
- **User feedback:** Whether users find the dashboard simple, clear, and easy to use.

Overall, my goal is to make cloud security easier to understand and manage. The dashboard helps users find important problems quickly, understand why they matter, and know what steps to take next.
